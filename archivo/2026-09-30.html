AI & Claude lesson: What is a token?

Language models do not read words; they read tokens. A token is a small chunk of text, often a whole short word, part of a longer word, or a punctuation mark. The model splits every input into tokens, processes them, and generates its answer one token at a time. As a rough guide for English, one token is about four characters, so 100 tokens is roughly 75 words. Spanish usually needs somewhat more tokens per word.

Tokens matter because they set both cost and limits. Providers bill by tokens read and written, and every model has a context window, the maximum number of tokens it can hold at once, covering your prompt, attached documents and its reply.

Example: a 10-page credit memo may run to several thousand tokens. If you paste it and ask for a summary, you pay for the memo and for the summary.

Practical use in banking: before automating a review of loan files, estimate tokens per file to forecast monthly cost and to check that file plus instructions fit in the context window. Trim boilerplate first.
