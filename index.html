AI & Claude lesson: What is a context window?

A context window is the maximum amount of text, measured in tokens, that a language model can consider at one time. It works like the model's working memory: your instructions, earlier messages, attached documents and the model's own reply all have to fit inside it. Anything outside the window is invisible to the model, and the model does not retain it between separate conversations.

In long conversations, the window fills up. Once it is full, older content must be dropped or summarized, which is why a model can seem to forget an instruction given at the start of a long chat. A larger window allows more material per request, but each request with more text also costs more and takes longer.

Example: you paste a 40-page loan agreement and ask ten follow-up questions. The agreement and every question and answer stay in the window, so the tenth answer is built on all of it.

Practical use in banking: when reviewing a credit file, include only the sections the question needs, such as financial statements and covenants, and put the key instruction at the start. This keeps answers focused and cost predictable.
